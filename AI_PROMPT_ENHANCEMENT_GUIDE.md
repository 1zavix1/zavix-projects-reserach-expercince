## 🎯 Stage 1: Pre-Launch (Week 1–2)

### Prompt 1: Delivery Costs by Wilaya (Perplexity)
```
Search for the current average home delivery fees charged by Yalidine and Maystro 
across all 58 wilayas in Algeria in 2025. Provide a table with:
- Wilaya name
- Home delivery cost (DZD)
- Stopdesk cost (DZD)
- Remote-area surcharges
```

### Prompt 2: Customs Duties (Perplexity)
```
What are the current customs duties and VAT rates for importing small electronics 
(posture correctors, smart watches) and fashion accessories from China and Turkey 
into Algeria in 2025?

Include:
- HS code categories
- Specific duty percentages
- VAT rate
- Simplified procedures under Auto-Entrepreneur framework
```

### Prompt 4: Payment Gateway Updates (Perplexity)
```
What is the latest method for Algerian e-commerce sellers to pay for Facebook 
and TikTok ads in 2025?

Include:
- Virtual card providers (RedotPay alternatives?)
- Binance P2P current status in Algeria
- Other payment gateway options
- Fees and reliability ratings
```

### Prompt 5: Ad Copy Variations (ChatGPT)
```
Act as a direct-response copywriter for the Algerian COD market. Write 5 different 
Facebook/TikTok ad captions for a posture corrector priced at 3,300 DZD.

Each caption must:
- Be under 50 words
- Use Darija or French
- Include a hook
- End with a clear CTA

Include: urgency variant, pain relief variant, social proof variant, emotional variant, direct variant.
```

### Prompt 6: Landing Page Content (ChatGPT)
```
Write the full product page copy for a posture corrector selling in Algeria.

Include:
- Headline (French/Darija)
- Subheadline
- 5 bullet points of benefits
- A short story about why posture matters
- A 3-step "how to use" section
- A trust section with COD and delivery info
- A FAQ section (5 questions)

Price: 3,300 DZD including delivery. Target: office workers, students, gamers.
```

### Prompt 7: WhatsApp Confirmation Scripts (ChatGPT)
```
Write two different WhatsApp confirmation messages for an Algerian COD order.

Both must ask the customer to reply "OUI" to confirm.

Version A: Warm and friendly
Version B: Direct and urgent

Include:
- Exact text in French and Darija
- Follow-up message if no reply in 2 hours
- Unconfirmed order cancellation message after 4 hours
```

## 🏭 Stage 2: Supplier Hunt (Week 2–3)

### Prompt 8: Supplier Negotiation Email (ChatGPT)
```
Draft a professional email to a Chinese supplier on Alibaba asking for samples 
of a posture corrector.

Include:
- Introduction as a serious buyer from Algeria
- Request for 3 samples with DHL shipping
- Questions about bulk pricing for 100 and 500 units
- Request for factory video and quality certifications
- Payment terms (30% deposit, 70% before shipping)
- Mention that you will reorder if quality is good

Keep it polite but business-like.
```

### Prompt 12: Unit Economics Deep Dive (Claude)
```
Using these inputs for an Algerian COD product:

- Retail Price: 4,500 DZD
- COGS: 1,500 DZD
- Shipping: 700 DZD
- Call Center: 150 DZD
- Packaging: 80 DZD
- Confirmation Rate: 60%
- RTS Rate: 25%
- Return Penalty: 250 DZD

Calculate:
1. Net profit margin before ad spend
2. Break-even CAC per delivered order
3. Minimum retail price to maintain 30% net margin after all losses
4. What happens if RTS increases to 30% and CAC increases by 20% simultaneously?

Show all steps and create a sensitivity table for RTS rates 15%, 20%, 25%, 30%.
```

### Prompt 13: Supplier Contract Risk Analysis (Claude)
```
Analyze this supplier contract (paste the text).

Identify:
- Red flags
- Unclear terms
- Potential risks for an Algerian buyer

Suggest modifications to protect against:
- Quality issues
- Shipping delays
- Payment disputes
- Customs problems

Provide a checklist of must-have clauses.
```

### Prompt 10: Extract Video Scripts from Competitors (Gemini)
```
Find 3 successful TikTok videos selling posture correctors (search in English, 
French, or Arabic). For each video:

- Transcribe the audio
- Provide the script structure: hook, body, call-to-action
- Note visual elements: text overlays, before/after shots, demonstrations
- Estimate views/engagement
```

```
- Emerging subcategories
```

## 📊 Stage 4: Scaling & Optimization (Week 4+)

### Prompt 3: Competitor Analysis (Perplexity)
```
Find active Facebook and Instagram ads from Algerian e-commerce stores selling 
posture correctors, back support braces, or similar health products.

Provide:
- Link to the ads (if public)
- Price points
- Offers (free shipping, discounts, bundles)
- Estimated ad lifespan
- Top 3 performing hooks you observe

Summarize competitive positioning.
```

### Prompt 14: Advanced Facebook Ads Strategy (Claude)
```
Create a 30-day Facebook Ads testing and scaling plan for a posture corrector 
in Algeria with a daily budget of 2,000 DZD.

Include:
- Week 1: Creative testing with 3 videos
- Week 2: Audience testing (broad vs. interest)
- Week 3: Offer testing (price, bundle, free shipping)
- Week 4: Scaling plan with budget increase rules

Provide exact metrics to monitor and decision thresholds for each phase.
```

### Prompt 15: Trending Products on X (Grok)
```
Search X (Twitter) for the latest viral e-commerce products in the health/fitness niche.

What are people talking about right now?

List:
- Product names
- Hashtags
- Relevant threads
- Sentiment (positive/negative)
- Estimated opportunity window
```

### Prompt 16: Sentiment Analysis on COD (Grok)

```
What is the current sentiment on X regarding cash-on-delivery in Algeria?

Identify:
- Common complaints about delivery times, RTS, scams
- How sellers are addressing these
- Emerging trust issues
- Suggested solutions

Top 5 issues ranked by frequency.
```
